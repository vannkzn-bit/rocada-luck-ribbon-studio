# Лента удачи — Design Studio

Автономная песочница для дизайн-адаптации механики «лента удачи» по HTML/EJS и CSS шаблонам Popmechanic/Mindbox. Это **демонстрация без интеграции с Mindbox**, выдачи настоящих призов и отправки форм.

## Возможности

- Три экрана: старт, выигрыш и подтверждение; повторный запуск и тестовый промокод.
- Фоновая прокрутка, ускоренный запуск с плавным торможением, точная остановка на выбранном призе.
- Случайный результат или принудительно выбранный приз; 2–12 призов.
- Горизонтальная и вертикальная лента, расположение сверху/снизу/слева/справа.
- Независимые размеры, фоны, стрелки и подложки карточек для Desktop и Mobile.
- Загрузка PNG, SVG, JPG, WebP до 8 МБ: фон, декор, логотип, карточки, стрелки, иллюстрация финала.
- Редактирование текстов, промокодов, палитры, типографики, размеров, отступов и скруглений.
- Автосохранение в IndexedDB, перенос проекта через JSON с вложенной графикой.
- Экспорт автономного HTML-превью со всей графикой, пригодного для открытия без сервера.
- Поддержка reduced motion. Тестовый email и согласие проверяются в браузере и не сохраняются.

## Использование

1. Во вкладке **Графика** загрузите изображения. Выберите Desktop или Mobile для фонов и стрелок соответствующей версии.
2. Во вкладке **Дизайн** настройте композицию, шрифт, цвета и тексты.
3. Во вкладке **Сценарий** выберите тестовый результат и продолжительность. Нажмите «Испытать удачу» в превью.
4. «Сохранить файл» скачивает весь проект в JSON. «Открыть» возвращает его в редактор.
5. «Сценарий → Скачать отдельное превью .html» создаёт переносимый файл без панели редактора.

Исходная стрелка должна смотреть вправо: приложение поворачивает её по направлению ленты. Изображение приза можно использовать как готовую карточку: установите размер 100% и отключите подписи.

Графика и настройки сохраняются только в конкретном браузере и на конкретном адресе. Они не загружаются в GitHub и не синхронизируются между устройствами. Для резервной копии скачайте JSON. При очистке данных браузера локальные проекты удаляются.

## Локальный запуск

Требуется Node.js 18 или новее; сторонние пакеты не нужны.

```sh
npm start
```

Откройте http://127.0.0.1:4173 . Альтернатива: `python3 -m http.server 4173 --directory dist`.

```sh
npm test
```

Проверки включают 308 сочетаний количества призов, позиции и выбранного результата, а также проверку импортируемых данных.

## Развёртывание

Приложение статическое. На GitHub Pages используется каталог `docs`, копия `dist`; включите Settings → Pages → Deploy from a branch → main → /docs. После изменения файлов `dist` обновите `docs` командой `node sync-pages.cjs`.

## Связь с исходным шаблоном

Сохранены структурные идеи: три экрана, повторяющаяся лента, указатели, изображения/подложки/подписи карточек, промокоды, параметры двух устройств. Серверные EJS-переменные заменены тестовой моделью в `dist/model.js`. Runtime Popmechanic/Splide отсутствует в документах: его поведение воспроизведено автономной анимацией requestAnimationFrame. Исходный скрипт принудительно скрывал второй и третий экраны; эта блокировка не перенесена.

Это не точный рендер произвольной конфигурации Mindbox и не готовый шаблон для обратного импорта в сервис. Списки полей платформы заменены демонстрационной email-формой. Настройки не вызывают API, вебхуки и CRM.

## Структура

- `dist/` — автономное приложение, исходные HTML/CSS/JS без сборки.
- `docs/` — копия для GitHub Pages.
- `server.cjs` — локальный сервер.
- `tests.cjs` — проверки механики и импорта.
- `sync-pages.cjs` — обновление каталога Pages.

Файлы исходных DOCX, изображения пользователя и ключи доступа не входят в репозиторий.
